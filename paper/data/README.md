# Paper data files

- `suite.txt` lists one npm package per line. `scripts/collect.mjs` runs
  each package's published CLI.
- `suite.json` is the collector's raw output: index entries, provenance,
  and mock runs at seeds 1 and 2. It is regenerated by
  `node scripts/collect.mjs`; `collectedAt` is the only volatile field.
- `defects.csv` holds the defect classes quoted in the
  independent-review section, one row per class. `class` is a hyphenated
  id, `packages` lists the affected package ids without the `benchmark-`
  prefix (semicolon-separated), `at_least` is the sourced minimum count
  of affected packages, and `source` names the public record the count
  comes from (changelog, issue, or pull request). Counts are minima
  because the paper states each as "at least" and the public record can
  hold more. The collector turns this file into
  `paper/generated/defects.tex`; do not type these numbers into `.tex`.
- `review-rounds.csv` counts independent-review fix rounds per package.
  It was derived on 2026-10-16 from the project's fix briefs: the count
  is the number of `bench-<id>-fix*.md` briefs each package received
  (`-fix.md`, `-fix2.md`, `-fix3.md`, and so on). One round can fix
  several defects, so the count is a proxy for review effort, not a
  defect count. All 22 packages needed at least one round; the median
  is 3 and the maximum is 9.
