\begin{abstract}
\texttt{benchmark-core} is a TypeScript engine for agent benchmarks.
\suitePackages{} packages publish on top of it.
Each package is one task set, one deterministic grader, a provenance record, and four runnable surfaces: an SDK, a command-line interface, an MCP server, and an HTTP handler.
The numbers below come from \texttt{scripts/collect.mjs}, which runs the packages named in \texttt{paper/data/suite.txt}.
A mock provider separates a scripted good policy from a scripted bad policy on every package.
This release has no public model leaderboard.
Results on real models are future work.
\end{abstract}
