The agent benchmarks we are closest to already score actions, not essays. SWE-bench asks a model to edit a real repository until the project's tests pass~\cite{jimenez2024swebench}. WebArena asks a browser agent to finish tasks on self-hosted sites and checks the resulting state~\cite{zhou2024webarena}. $\tau$-bench runs a tool-using agent against a simulated user and a policy, then compares the database to the goal~\cite{yao2024taubench}. AgentBench spreads a similar question across several environments~\cite{liu2024agentbench}. BFCL scores function calls, including the decision to abstain, with an abstract-syntax check rather than a free-form judge~\cite{patil2025bfcl}. We do not offer a substitute for any of those task sets. The overlap is the habit of grading a trace against a state. The difference is the unit of distribution: one npm package, a mock provider, and a grader that a second machine can run with no key.

The harnesses solve a different packaging problem. HELM argues for many metrics on a shared set of scenarios, and it ships a toolkit to do that~\cite{liang2023helm}. The EleutherAI evaluation harness is the usual way to point one model at a large menu of few-shot tasks~\cite{gao2024lmeval}. Inspect, from the UK AI Security Institute, is a Python framework for tool use, multi-turn work, and model-graded scores~\cite{aisi2024inspect}. All three are places you bring a model. \texttt{benchmark-core} is a place you bring a task set, and the model adapter is one of three. A package that only needs a deterministic replay should not have to adopt a second harness to be runnable.

Contamination and saturation are why a small public suite is a weak leaderboard. Sainz and colleagues argue that a model trained on a test split will look better than it is, and that the field should measure that per benchmark~\cite{sainz2023contamination}. Dehghani and colleagues showed that swapping the benchmark can reorder methods that people had treated as ranked~\cite{dehghani2021lottery}. Our response is modest. Generators are seeded, the public seed is in the provenance command, and a hidden split is a documented flag rather than a file in the package. We also refuse to print a model table until someone has actually run the models. An index field for saturation exists. In this release it is \texttt{\suiteSaturation{}}.

Reward hacking is the formal version of a grader that can be gamed. Skalse and colleagues define a proxy as hackable when improving the proxy can make the true objective worse~\cite{skalse2022hacking}. A benchmark grader is a proxy. We do not prove our graders unhackable. We do the smaller thing their definition suggests is worth doing: write down the cheap policies that should not win, and fail the build if they do. That is the end-to-end guard in each package. It will miss a clever attack. It will catch a constant answer.

The MCP server speaks the Model Context Protocol~\cite{mcp2025spec}. We use it as a transport for the five tools in Section~\ref{sec:engine}. Tool descriptions are untrusted input. The MCP-safety package is about that fact. The protocol document's own security notes say the same thing, and a benchmark does not enforce them by existing.

Willison's pelican prompt is prior art from a blog post~\cite{willison2024pelican}. He chose it because he liked the bird and because he did not think the training sets already contained the drawing. The structural grader in our package is not the same check as looking at the SVG. Both can be right about a different question.

The newer packages borrow their threat models from published attacks and evaluations. Wallace and colleagues define the instruction hierarchy in which system rules outrank user, history, and tool text, and train models to ignore lower-priority instructions~\cite{wallace2024instruction}; IHEval measures that ordering with rule-checked examples~\cite{zhang2025iheval}. Our instruction-hierarchy package asks the same question with deterministic assertions and extractor probes instead of a judge. AgentDojo grades agents that run tools over untrusted data under prompt injection~\cite{debenedetti2024agentdojo}; mcp-safety and checkout-consent cover the same ground as seeded, replayable episodes. PerMemBench evaluates what a memory system chooses to store~\cite{in2026permembench}; memory-conflict instead asks whether the agent applies the latest valid memory. The accessibility package cites WCAG 2.2 success criteria by number~\cite{w3c2024wcag22} and re-implements a small deterministic subset rather than a browser engine.
