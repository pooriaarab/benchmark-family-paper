Section~\ref{sec:review} measured what the probing review found; this section asks what is true of the graders as shipped. Three checks run offline on the pinned artifacts: a frozen battery of contract probes, an audit of what each tarball holds back, and a determinism run. The checks measure behaviour on the listed probes and files only.

\paragraph{Contract probes.}
A frozen probe list was committed before any probe ran, and each probe applies one transform to the per-task oracle submission (the list and the oracle definition are in Appendix~\ref{app:experiments}). Honest variants reformat the oracle answer only in ways a shipped document promises, such as one surrounding code fence or prose around the answer. Attacks try to earn credit without doing the task: every candidate answer at once, the prompt echoed back, a score-injection suffix, an oversized answer, duplicated tool calls, and forged tool results, final state and score fields. A cell passes when its frozen rule holds at the pinned version. Probes a package never promised are marked outside contract, and a probe that cannot run as written is marked not runnable; Figure~\ref{fig:probes} hatches both rather than reading them as pass or fail. Of the \expProbeCells{} cells over the \expArtifacts{} artifacts, \expProbesOutsideContract{} sit outside contract and \expProbesNotRunnable{} could not run.

Every promised honest variant held at the released versions: \expProbesHonestHeld{} of \expProbesHonestCells{} promised cells, spread over the \expProbesHonestPromised{} released graders that publish a normalisation the probes use; the other \expProbesHonestUnpromised{} released graders promise none, so nothing was claimed or broken there. The attacks still find defects at the released versions, reported here as found, with no fix claimed. \expProbesFailedCells{} of the \expProbesReleasedCells{} released-version cells break their frozen rule. \expProbesMovedFailCells{} of them are type-B fails on \expProbesMovedFailPkgCount{} graders, cells whose frozen rule requires the probe score to equal the oracle's. \expProbesDupCallCells{} of those are duplicated tool calls on \expProbesDupCallPkgs{}, which score a repeated side effect zero by design, so the flag marks a documented penalty rather than a defect (the orange cells in Figure~\ref{fig:probes}). The remaining \expProbesWrapCells{} are text wraps on \expProbesWrapPkgs{}: a prompt echo or a score-injection suffix moves a strict grader off the oracle score, so an honest answer loses credit it earned bare. The other \expProbesCreditFailCells{} are type-A fails on \expProbesCreditFailPkgs{}, cells where content that never did the task scores above an empty submission. Forged-field acceptance is \expProbesForgedAccepted{} of \expPackages{}: fabricated tool results earn retry credit on \texttt{tool}-\allowbreak\texttt{errors}, and any non-empty answer counts as a communicated refusal on the decline tasks of \texttt{payment}-\allowbreak\texttt{delegation}. On \texttt{schema}-\allowbreak\texttt{mutation} the all-candidates answer scores full marks on every task. For the \expWaveTwo{} packages with a single release the probe rows describe what is shipped today, with no earlier version to compare.

\paragraph{Hidden-split audit.}
The audit scans all \expAuditArtifacts{} shipped tarballs for files whose path names a hidden or held-out split, non-public files carrying answer-shaped content, and concrete seed values printed in shipped documentation. No tarball ships a hidden-named file. The content detector flags \expAuditLeaksFound{} file: the README of skateboard 0.1.0 prints a public task's expected answer verbatim, an exposure of public data in documentation; the audit reports it for the reader to judge rather than calling it a held-out leak. The documentation scan also collects \expAuditSeedExamples{} seed-like values printed next to hidden-split wording; \expAuditSeedExamplesOther{} of them differ from the public seed \suitePublicSeed{} and are not years, and those narrow what a held-out split can keep secret.

Where a shipped generator can regenerate a hidden split, the audit measures overlap with the public one at \expAuditSeeds{} frozen seeds; \expAuditCensusQualified{} artifacts qualify, and Figure~\ref{fig:hiddenaudit} in Appendix~\ref{app:results} plots the exact-match shares. Regenerated hidden splits still collide with the public split at the earlier pelican release and at the current cost-per-task release: exact-match overlap reaches \expAuditMaxPromptOverlapPct\% of prompt pairs and \expAuditMaxExpectedOverlapPct\% of expected-answer pairs, and every hidden id at the cost-per-task release is a public id under a prefix, an \expAuditMaxIdSuffixPct\% suffix overlap. The current pelican release and accessibility-fix generate disjoint splits. \expAuditSeedlessQual{} of the qualified artifacts, the earlier pelican release and accessibility-fix, fall back to the public seed when no seed is passed, so a hidden run without a seed reproduces the public split; the frozen seeds always pass one, so that path never fires in the measured cells.

\paragraph{Determinism.}
Each released grader ran the offline mock provider at seeds \expDetSeedList{} and concurrency \expDetConcurrencyList{}, \expDetRepeats{} repeats per cell, and the trivial-server path repeated \expDetRepeats{} times per package: \expDetRuns{} runs in all, of which \expDetFailedRuns{} failed. Each run hashes its task, score and reason rows, and a package counts byte-identical when every run in each of its groups produces the same hash. \expDetIdentical{} of \expDetPackages{} packages are byte-identical. The exception is \expDetDriftPkgs{}, which drifts on both arms because its grader measures wall-clock time between turns and bills the measured time against the model's budget. Identical submissions can earn different scores between runs; the drift is a property of that grader's contract, which prices real time, so the run records it by name.

\paragraph{What these checks do not show.}
A pass means the frozen rule held on the listed probes at the pinned versions; it says nothing about probes that were never written, and the author wrote this list knowing the logged defects, so freezing it before the run is a weak registration. The audit inspects shipped files only: a public task can sit in a model's training data whatever the tarball holds. Every determinism run goes through the deterministic mock adapter or the vendored trivial server, so the check says nothing about variance under a real model. The honest reading is narrower than soundness: on these probes, at these versions, the released graders keep every promised normalisation, \expProbesWrapPkgCount{} still dock an honest answer wrapped in a prompt echo or a score line, \expProbesDupCallPkgCount{} penalise a repeated tool call as designed, and the released graders of \expProbesCreditFailPkgs{} still pay content that never did the task.
