\section{Experiment specifications and frozen probe lists}
\label{app:experiments}

This appendix is the reference for the scripted checks that Sections~\ref{sec:prereg} and \ref{sec:soundness} report: what each run is, which input list was frozen before it ran, which files hold its output, and what it cannot show. Table~\ref{tab:experiments} gives the summary and the paragraphs below name the frozen inputs. Everything ran offline, free and deterministically against the artifacts pinned in \texttt{scripts/exp/versions.json} (\expArtifacts{} tarballs, each checked against its pinned \texttt{sha512} on install by \texttt{scripts/exp/install.mjs}); each script carries a failure-modes note beside it in \texttt{scripts/exp/}, and \texttt{paper/data/exp/README.md} describes every output file. Regeneration is covered in Appendix~\ref{app:reproducibility} and the deviations from the registered record in Appendix~\ref{app:deviations}.

\paragraph{The frozen lists.}
Every run that scores against a list had the list committed before the run. The trivial battery's zero-row classes sit in \texttt{scripts/exp/reason-classes.json}: \expReasonClasses{} declared classes (format-gate, contract-violation, wrong-answer, abort) over \expReasonClassRules{} regex rules, shared rules first and then per-package rules for all \expReasonClassPkgs{} packages, with first-match precedence and an unclassified remainder that is counted, never dropped. The contract-probe list is \texttt{scripts/exp/probes.json}: \expProbes{} probes, \expProbesHonest{} honest variants that reformat the oracle answer only in ways a shipped document promises, \expProbesAttack{} attacks, and \expProbesExploratory{} unpromised exploratory probe reported but never counted as a defect; the per-artifact applicability contract is \texttt{paper/data/exp/probe-applicability.csv} and the oracle definition is \texttt{paper/data/exp/oracle-definition.csv}. The exploit list is \texttt{paper/data/exp/exploits.csv}: \expExplFrozen{} frozen rows, each joining a logged number or bound to the package, locator, policy description, version pins and comparison clauses it is measured under; the results land in the three files \texttt{exploit-results-\{a,b,c\}.csv}. The audit seeds are \texttt{scripts/exp/hidden-seeds.json} (\expAuditSeeds{} seeds, never the public seed) and the determinism grid is \texttt{scripts/exp/determinism.json}.
