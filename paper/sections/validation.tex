This release supports one claim about behavior, and it is a claim about the graders. Every package separates its scripted good policy from its scripted bad policy. Table~\ref{tab:mock} is the measurement. The good column is 1 on every package, and the weakest individual good task is still \suiteGoodFloor{}. The bad column is 0 except where Section~\ref{sec:suite} explains a partial: tool-errors can keep a safety term, and honesty can keep a calibration sliver. The highest bad task in the run is \suiteBadCeiling{}.

Seed 1 is the default mock mix. Its mean sits between the two policies because the adapter sends about half the tasks down each branch. The interval around that mean is the engine's bootstrap. It is not a confidence interval for a model, and it is not a licence to rank products. Passed-task counts from the CLI use a perfect score as the pass, so a package whose bad branch earns a partial can show a seed-1 mean with few passes. We report means, not a pass rate, for that reason.

Mock cost on every package is \suiteMockCost{}. That checks the accounting path. It does not estimate a real model's bill.

Re-running the collector is the reproducibility check we actually did. \path{node scripts/collect.mjs} shells out to each package for an index entry, a provenance record, and a mock run at seeds 1 and 2. The package list is \texttt{paper/data/suite.txt}. Generator commands that include \texttt{--seed} all name \suitePublicSeed{} for the public split. Package versions in this build are \suiteVersion{}, and every index entry reports status \texttt{\suiteStatus{}}. Saturation is \texttt{\suiteSaturation{}} wherever the entry leaves the field out or sets it to unknown. No entry reports a number.

The end-to-end script in each package is a separate guard. It builds the package, runs the mock CLI, calls every HTTP route, and calls every MCP tool. Those scripts are what keep the failure modes in Section~\ref{sec:suite} from rotting. We did not re-execute all twelve of those scripts for this paper. The numbers in the tables come only from the published CLIs.

What we do not claim is the part that usually gets a table of its own. There is no public leaderboard. We did not run a hosted model. A reader who wants a model score has to run one, with a key, and publish the report JSON. Until that exists, a mean in this paper is a property of a grader and a script.
