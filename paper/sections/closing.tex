Every wave-2 number is exploratory, because those packages have a single release and some already carry review fixes; the registered real-model arm is unmeasured, no cells are vendored in this repository, and this paper reports no model numbers. \paragraph{What the measured numbers still do not show.}
No real model was run for this paper: every measured number is a property of a grader and a script, so it says nothing about whether the suite discriminates between real systems or how much of any public split a training set already holds. Deterministic graders also limit what they measure: pelican's structural check accepts some drawings a person would reject, test-weakening's evaluator accepts only a small expression language, and crm-truthfulness ships as alpha with a documented lexical miss rate, so a score on these packages reports how a replayed trace was graded rather than what an agent intended. The saturation field in every index entry stays \texttt{\suiteSaturation{}} on purpose, ranking statistics need several model reports that do not exist, and \texttt{cost-per-task} depends on a price snapshot a provider can change.

\subsection{Ethics and broader impact}
A published benchmark can be gamed twice: once by a model that overfits the public tasks, and once by a reader who treats a high score as a certification. Several packages are about refusal, consent, or not leaking a secret, and a high score says nothing about what to buy or whether a deployment is safe; checkout-consent must not be pointed at a real card, mcp-safety not at a tool server holding real credentials, and test-weakening's expression evaluator is not a security boundary. The tasks are synthetic or written by the maintainer, licences are per source (Appendix~\ref{app:reproducibility}), and sycophancy labels are a single maintainer's judgement, so the benchmark should not be used to punish a model for a contextual judgement the label got wrong. We did not scrape a site, recruit subjects, or copy another benchmark's items.
