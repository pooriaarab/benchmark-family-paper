\subsection{Limits of the evidence}
The mock separation shows that the grader is not a constant function. It does not show that a careful model cannot find a hole the scripted bad policy missed. The end-to-end attacks are the cheap ones. A grader that checks structure, as pelican does, will accept some drawings a person would reject, and it will reject some drawings a person would accept. Test-weakening's evaluator accepts a small expression language. A model that writes ordinary JavaScript the evaluator does not understand fails even if the tests would pass. Ranking statistics need several model reports. We have the command and not the reports.

Public tasks can be memorized. The contamination note on each package says to generate a hidden split and keep it out of the package. We have not run that protocol against a model, so we do not know how much of the public split is already in any training set. Saturation is unmeasured. The index field is empty or \texttt{unknown} on purpose.

\texttt{cost-per-task} depends on a price snapshot that the provider can change. A rerun months later can disagree about dollars even when the tool trace is identical. Reports should name the package version and the snapshot date. The snapshot date is the provenance \texttt{retrievedAt}, not a number we invent here.

\subsection{Ethics and broader impact}
Several packages are about refusal, consent, or not leaking a secret. A high score is not a certification, a purchasing decision, or a claim that a deployment is safe. Checkout consent uses a fake shop and a test payment. It must not be pointed at a real card. MCP safety uses a canary string. It must not be pointed at a production tool server that holds real credentials.

Test-weakening will execute model-written expressions inside the grader's process. The syntax whitelist is not a security boundary. Run it in a disposable environment, with no keys in the environment and no network it can use. The mock provider only replays committed fixtures, which is the path this paper measured.

The tasks are synthetic or written by the maintainer, except the public-domain pelican prompt and the OpenStax formula citation in skateboard. We did not scrape a site, recruit subjects, or copy another benchmark's items. Sycophancy labels are a judgement about harm. A second reader can disagree, and the repository says how that disagreement should be handled. The benchmark should not be used to punish a model for a contextual judgement the label got wrong.
