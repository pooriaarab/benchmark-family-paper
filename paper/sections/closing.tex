\subsection{Limits of the evidence}
No real model was run for this paper. Every measured number is a property of a grader and a script, not of a language model. The mock separation shows that the grader is not a constant function. It does not show that a careful model cannot find a hole the scripted bad policy missed. The end-to-end attacks are the cheap ones. A grader that checks structure, as pelican does, will accept some drawings a person would reject, and it will reject some drawings a person would accept. Test-weakening's evaluator accepts a small expression language. A model that writes ordinary JavaScript the evaluator does not understand fails even if the tests would pass. Ranking statistics need several model reports. We have the command and not the reports.

Public tasks can be memorized. The contamination note on each package says to generate a hidden split and keep it out of the package. We have not run that protocol against a model, so we do not know how much of the public split is already in any training set. Saturation is unmeasured. The index field is empty or \texttt{unknown} on purpose.

\texttt{cost-per-task} depends on a price snapshot that the provider can change. A rerun months later can disagree about dollars even when the tool trace is identical. Reports should name the package version and the snapshot date. The snapshot date is the provenance \texttt{retrievedAt}, not a number we invent here.

\subsection{Ethics and broader impact}
Several packages are about refusal, consent, or not leaking a secret. A high score is not a certification, a purchasing decision, or a claim that a deployment is safe. Checkout consent uses a fake shop and a test payment. It must not be pointed at a real card. MCP safety uses a canary string. It must not be pointed at a production tool server that holds real credentials.

Test-weakening evaluates model-written expressions in child processes (a pool of four) behind a closed grammar; where a runtime cannot spawn child processes, the package documents a fallback to in-process evaluation with only the structural limits and no wall-clock kill. That is still not a security boundary. Run it in a disposable environment, with no keys in the environment and no network it can use. The mock provider only replays committed fixtures, which is the path this paper measured.

The tasks are synthetic or written by the maintainer, except the pelican-on-a-bicycle prompt popularised by Simon Willison and the OpenStax formula citation in skateboard. The pelican package declares CC0 for the canonical prompt and MIT for the seeded grid it generates; we did not verify the prompt's licence ourselves. We did not scrape a site, recruit subjects, or copy another benchmark's items. Sycophancy labels are a judgement about harm. A second reader can disagree, and the repository says how that disagreement should be handled. The benchmark should not be used to punish a model for a contextual judgement the label got wrong.

\subsection{Assistance, reproducibility, availability}
The code and this draft were produced with AI coding agents under the author's direction and review. The agents wrote most of the implementation and a first pass of the prose. The author is responsible for what shipped, including the decision to publish no model scores.

To regenerate the tables, install Node 20 or newer and run \texttt{node scripts/collect.mjs} from a checkout of this repository. The script's only network use is \texttt{npx} resolving the packages named in \texttt{paper/data/suite.txt}. To rebuild the PDF, install Tectonic 0.17.0 and run \texttt{make pdf}. The bootstrap seed and the resample count are the engine defaults unless a caller overrides them. Public task generators use seed \suitePublicSeed{} where the provenance command prints \texttt{-{}-seed}.
