A benchmark in this family is a call to \texttt{defineBenchmark} on \texttt{benchmark-core}, a shared TypeScript engine: the call produces an SDK import, a command-line interface, an MCP server and a fetch-style HTTP handler per package, and a mock provider runs every grader offline with no key. Appendix~\ref{app:engine} gives the call's contract, the snippet shape and the surface details. Coding agents built the \suitePackages{} packages in this suite under that contract; Appendix~\ref{app:builders} counts the agent trailers and pull requests behind them. Table~\ref{tab:suite} lists each package with the version this paper measures, and Table~\ref{tab:suite-full} in Appendix~\ref{app:suite} gives the full catalogue columns.
